## 2. أعطال حقيقية كشفتها شبكة الدخان

الشبكة أثبتت قيمتها بأول تشغيل كامل: لقِطت عطلين ما كان في شي يحرسهما.

### FIX-01 — `/travel-atlas/countries` كان ينهار على كل تحميل فاشل ✅ مُصلَح

```
TypeError: Cannot read properties of undefined (reading 'filter')
  at src/features/travel-atlas/pages/CountryStampsPage.tsx
```

السبب الجذري **ليس** غياب معالجة الحالة الفارغة — بل أن المعالجة كانت
مكتوبة بالشكل الخطأ:

```ts
const { data: stamps = [], isLoading } = useCountryStamps();
```

القيمة الافتراضية بالتفكيك بتشتغل على `undefined` **بس**، ما بتشتغل على
`null`. والاستعلام هاد بيرجّع `null` بالضبط لما يفشل الجلب والكاش يكون بارد.
بعدها كل `stamps.filter(...)` بيرمي، والصفحة بتروح لحدود الخطأ العامة.

الملفت إنّه المشروع **عارف النمط الصحيح أصلاً** — `src/features/travel-atlas/hooks.ts`
بيستعمل `?? EMPTY_STAMPS` مع ثابت على مستوى الوحدة، وفوقه تعليق بيشرح ليش
الثابت ضروري (ما يصير مصفوفة جديدة كل رندر فتبطّل كل الـmemos تحتها).
الصفحة بس ما مشيت على النمط. هاد تطبيع أنماط، مو اختراع حل.

**نطاق أوسع:** نفس الشكل غير الآمن موجود بـ**11 موضع**:

### FIX-02 — `/chat/g/:chatId` ينهار على اشتراك realtime ⛔ غير مُصلَح

```
Error: cannot add `postgres_changes` callbacks for realtime:chat:<id>
       after `subscribe()`.
  at src/lib/chat/hooks/useChatMessages.ts:147
```

القناة بتستقبل `.on()` بعد ما تكون `subscribe()` انستدعت. هاد سباق بدورة
حياة الاشتراك، مو مجرد ضجيج اختبارات: نفس التسلسل بيصير بالإنتاج كل ما
المكوّن يعيد التركيب بسرعة (تنقّل سريع، أو التركيب المزدوج بـStrict Mode).
النتيجة قناة بلا مستمعين — رسائل ما بتوصل، بلا أي خطأ ظاهر للمستخدم.

ما انصلح هون عن قصد: إصلاحه بيعني إعادة ترتيب دورة حياة الاشتراك، وهاد
تغيير سلوكي بقلب الشات. ينتمي لمرحلة العزل مع اختبار يثبت السباق أولاً.

## 3. ليش شبكة الدخان مجزّأة لعمليات منفصلة

أول تشغيل كامل وقف عند المسار **34 من 83** وقعد أكتر من ربع ساعة بلا تقدّم،
و**مهلة الـ30 ثانية لكل اختبار بفيتست نفسها ما اشتغلت ولا مرة**.

ثلاث تجارب حصرت السبب:

1. كل مسار لحاله بيمرّ بحوالي 5 ثواني — بما فيه `/german-club/grammar`
   اللي وقف عنده التشغيل. فالعطل مو بمسار معيّن.
2. تعطيل الشبكة ما غيّر شي. فالعطل مو انتظار I/O.
3. شريحة من 6 مسارات بتخلص بـ15 ثانية بشكل ثابت. فالعطل **تراكمي**.

التفسير: `cleanup()` بيفكّ شجرة React، بس المخازن وحدات مفردة على مستوى
الموديول — المؤقتات وحلقات الاستطلاع والاشتراكات اللي بتسجّلها عند أول
استيراد ما بتنفكّ أبداً، لأنه ما حدا تخيّل عملية بتركّب التطبيق 80 مرة.
بعد حوالي 34 تركيب، بيكون عدد كافي منها شغّال بالتوازي لدرجة بتخنق حلقة
الأحداث — وعندها حتى مؤقت المهلة نفسه ما بيوصله دور.

**هاد بحدّ ذاته نتيجة عن قصة التفكيك بالتطبيق** (مسجّلة للمرحلة اللاحقة).
بس شبكة الأمان لازم تجي **قبل** إصلاحه، لأنها هي اللي رح تحمي الإصلاح.
فالمشغّل بيشتغل ضمن القيد: كل شريحة عملية جديدة بسجلّ وحدات نظيف، فالمؤقتات
المتسرّبة بتموت معها.

```
$ bun run test:smoke
Route smoke: 12 shards, one process each.

▸ shard 1/12 … ok (15.1s)
…
▸ shard 12/12 … FAILED (300.1s, exit null)

✗ 3/12 shard(s) failed: 9, 11, 12
Re-run one with:  SMOKE_SHARD=9/12 bun run test:smoke
```

المهلة بالمشغّل (5 دقايق للشريحة) هي الشبكة الاحتياطية اللي ما قدرت مهلة
فيتست توفّرها. اشتغلت بالضبط كما صُمّمت.

### كعب الشبكة لازم يكون محصوراً بالخلفية

أول نسخة من الكعب جاوبت **كل** طلب بـ`[]`. هاد كسر الصفحات اللي بتجلب
بياناتها الثابتة بنفسها: `loadWorldDots()` استلم مصفوفة فاضية بدل مستند
`{ countries: [...] }`، فـ`/travel-atlas/countries` فشل بانهيار **الكعب هو
اللي صنعه**.

شبكة أمان بتخترع أعطال أسوأ من لا شي، لأن اللي بعدك بيتعلّم يتجاهلها.
فالكعب صار محصور بمضيف Supabase وحده؛ وكل شي غير هيك بيفشل متل ما بيفشل
بـjsdom عادي — وهي حالة محمّلات التطبيق أصلاً لازم تتعامل معها.

## 4. البوابات الجديدة

الثلاثة بتشتغل بنفس المبدأ: **قِس اليوم، جمّد الرقم، اسمح بالنزول بس.**
السبب بالتدقيق: `designSystem.test.ts` كان عنده ميزانية 1800 لـ`text-[Nrem]`
مقابل عدد فعلي 170 — بوابة ما بتقدر تفشل.

### `scripts/arch-check.mjs`

بيبني رسم الاستيراد الحقيقي (static + `import()` + `require()`) وبيفرض خمسة
ثوابت. القيم المجمّدة اليوم:

```json
{
  "cycles": 2,
  "orphans": 25,
  "crossFeatureImports": 6,
  "rawSupabaseUsage": 55,
  "rawSupabaseEnvUsage": 3
}
```

هالأرقام **مو أهداف** — هي اعتراف. المقصود منها توقيف النمو الصامت بينما
الطبقات المتبقية من الخطة بتنزّلها.

**مُثبَت إنها بتفشل فعلاً:** بحقن ملف يكسر حدّين (استيراد ميزة لميزة ثانية +
عميل Supabase خام)، البوابة خرجت بـexit 1 وسمّت الانتهاكين، وبعد حذف الملف
رجعت خضراء. بوابة ما انجرّبت على الفشل هي زينة.

### `scripts/bundle-budget.mjs`

`renovate.json` كان بيطلب فحص `"Enforce bundle budget"` من يوم ما انكتب،
و**ما كان في لا فحص ولا سكربت بهالاسم**. هلأ في.

بيقيس بضغط **brotli**، لأنه هو اللي بينزّله المستخدم فعلاً. وهاد بيقلب
الترتيب رأساً على عقب:

| chunk | خام | brotli |
|---|---|---|
| `BayanDashboard` | 6.40 MB | ضئيل |
| `icons` | 3.35 MB | **997 KB** |
| `maplibre` | 1.02 MB | 362 KB |
| `useDictionaryStore` | 2.37 MB | 59 KB |

العبء الحقيقي **`icons`**، مو لوحة بيان. الأرقام الخام كانت بتوجّه الجهد
للمكان الغلط. المجموع المجمّد: **3311.5 KB** عبر 228 chunk، بهامش 2%
للضجيج (ميزانية بتنكسر على الضجيج بترتفع تلقائياً وبتفقد معناها).

### `.github/workflows/verify.yml`

أربع وظائف، وأسماؤها **تعاقدية** لأن `renovate.json` بيعلّق الدمج التلقائي
عليها حرفياً:

| الوظيفة | شو بتحمي |
|---|---|
| `verify` | typecheck · lint · budgets · arch · tests · build |
| `npm install parity` | **حارس BUILD-01** |
| `Enforce bundle budget` | نمو الحزمة |
| `e2e` | Playwright على نتاج الإنتاج |

`npm install parity` مضافة لسبب محدد: `bun` بيركّب الـpeer deps تلقائياً.
هاد بالضبط ليش ضياع `postprocessing` من `package.json` كان خفي —
بيبني تمام محلياً، وبينهار على أي مدير حزم ثاني. الوظيفة بتثبت إن
`package.json` لحاله بيان كامل وقابل للتركيب.

## 5. الشغلة الوحيدة اللي ما قدرت تنفّذ من هون

الهجرة `20261005120000_close_anon_read_leaks.sql` **مكتوبة وما انطبّقت**.
المنفذ الشبكي لـ`nmrckgzmluoavgucqvjh.supabase.co` مقطوع من هالبيئة، فما
في طريقة أطبّقها ولا أتحقق منها.

بتسكّر SEC-01 و SEC-02. لحد ما تنطبّق، **جداول الأماكن وصورها لسا مقروءة
لـ`anon`** — يعني إحداثيات GPS لمواقع مستخدمين حقيقيين. هاد البند الوحيد
بالمرحلة 0 اللي لسا مفتوح، وهو أخطرهم.

للتطبيق:

```bash
supabase db push
# أو: supabase migration up --linked
```

بعدها، التحقق إنه فعلاً انسكّر:

```bash
bun run test -- src/test/rlsHostileClient.test.ts
```

هالمجموعة ما عاد تقدر تمرّ من دون ما تشتغل. قبل اليوم كانت بتخرج من أول
سطر بـ8 ميلي ثانية لأن `import.meta.env.VITE_SUPABASE_*` كانت `undefined`،
فـ`anon` كان `null` وكل الـ30 حالة بترجع فوراً. المخطط والاختبار كانوا
بيناقضوا بعض طول ما الاثنين موجودين.
