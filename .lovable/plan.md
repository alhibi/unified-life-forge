# خطة تحويل SmartHub إلى بوابة شخصية متعددة التطبيقات

## الرؤية

بدل شريط سفلي مكتظ بست تبويبات + ميزات مبعثرة في الصفحة الرئيسية، تصبح `/` بوابة شخصية أنيقة (Personal Portal) تعرض سبعة "تطبيقات" مستقلة، كل واحد بأيقونته وهويته وصفحته الكاملة. الإحساس: مثل شاشة رئيسية لنظام تشغيل شخصي، لا مثل تطبيق واحد مزدحم.

## الصفحة الرئيسية الجديدة `/`

تخطيط عمودي هادئ:

```text
┌─────────────────────────────────────────┐
│  [Avatar]                    [Settings] │  ← الزاوية العلوية
│                                         │
│                                         │
│              ✦  الاسم / تحية             │  ← وسط-أعلى
│           [ أيقونة متوسطة ]              │  ← الأيقونة المركزية → /hub
│                                         │
│                                         │
│   ┌──────┐ ┌──────┐ ┌──────┐            │
│   │ App1 │ │ App2 │ │ App3 │            │  ← شبكة التطبيقات
│   ├──────┤ ├──────┤ ├──────┤            │
│   │ App4 │ │ App5 │ │ App6 │            │
│   ├──────┤ └──────┘ └──────┘            │
│   │ App7 │                              │
│   └──────┘                              │
│                                         │
│              Made by Amer               │
└─────────────────────────────────────────┘
```

- زاوية علوية: أيقونة الملف الشخصي (يمين/يسار حسب اللغة) → `/profile`، وبجانبها ترس الإعدادات → `/settings`.
- وسط-أعلى: أيقونة مركزية متوسطة (رمز الهوية) → عند النقر تنتقل إلى محطة `/hub` (شاشة انتقالية سينمائية تعرض الأقسام السبعة بشكل موسّع، اختياري في المرحلة الثانية — في المرحلة الأولى تفتح لوحة أوامر أو تنقل بصري).
- شبكة التطبيقات: 7 بطاقات مربّعة كبيرة، كل واحدة أيقونة + اسم + لون accent خاص. الضغط ينقل إلى الصفحة الجذر لذلك التطبيق.

## التنقّل — إلغاء الشريط السفلي بشكله الحالي

- الشريط السفلي بستة تبويبات يُستبدل داخل صفحات التطبيقات بـ **زر رجوع عائم للبوابة الرئيسية** (أيقونة صغيرة في الأسفل، ثابتة عبر الميزات).
- داخل كل "تطبيق" يستخدم `BackButton` القياسي مع رجوع دائم إلى `/`.
- كل ما يخص الصفحة الرئيسية القديمة (Weather widget، PrayerTimes، UmmahPulse، CurrentTimeSunnah، Saved Locations، Living Ribbon) ينتقل إلى صفحة `Now` (`/now`) — أي أن الرئيسية الحالية تصبح "تطبيق الرئيسي" مثل الباقين.

## البنية التقنية

### ملفات جديدة

- `src/pages/Portal.tsx` — الصفحة الجذر `/` الجديدة (البوابة).
- `src/components/portal/AppTile.tsx` — بطاقة تطبيق (icon + label + accent + press animation).
- `src/components/portal/PortalHeader.tsx` — Avatar + Settings في الزاوية، أيقونة مركزية.
- `src/components/portal/PortalBackButton.tsx` — زر رجوع عائم يظهر في كل الصفحات الفرعية.
- `src/features/now/pages/Now.tsx` — نقل محتوى `Index.tsx` القديم إلى هنا.
- `src/features/now/index.ts`.

### تغييرات في التوجيه (`src/App.tsx`)

- `/` → `Portal` (بدل `Index`).
- `/now` → `Now`.
- إزالة `BottomNav` من التنسيق العام.
- إبقاء `PersistentTabs` مع تحديث `TAB_PATHS` لتشمل `['/', '/now', '/chat']` بحيث تبقى البوابة و Now والدردشة مثبّتة (تجربة فورية).
- إضافة `<PortalBackButton />` عالمياً يظهر في كل مسار عدا `/`.

### التوافق مع الروابط القديمة

- `/index` القديم → `Navigate` إلى `/`.
- كل المسارات الحالية للأقسام تبقى كما هي — فقط نقطة الدخول تغيّرت.

## المراحل التنفيذية

1. **بناء البوابة**: `Portal.tsx` + `AppTile` + `PortalHeader` + accent tokens لكل تطبيق. تصميم بنفس هوية Obsidian Luxury.
2. **نقل الرئيسي إلى Now**: نسخ محتوى `Index.tsx` القائم إلى `src/features/now/pages/Now.tsx` مع تحديث SEO.
3. **إعادة توجيه وتحديث `App.tsx`**: `/` → Portal، `/now` → Now، إزالة `BottomNav` من الشيل العام، إضافة `PortalBackButton` عائم.
4. **زر الرجوع العائم**: يظهر على كل الميزات ما عدا `/`، ينقل مباشرة إلى `/`.
5. **توحيد صفحة المعرفة**: صفحة هبوط `/knowledge` بسيطة تعرض بطاقتَي "الأرشيف المعرفي" و"مذكّرتي" و"الموسوعة الشخصية" بشكل أنيق.
6. **تحديث الذاكرة والوثائق**: تحديث `docs/architecture/information-architecture.md` و `mem://index.md` لتعكس النموذج الجديد.

## التصميم البصري

- شبكة التطبيقات: بطاقات 2 أعمدة على الجوال، أنيقة، `rounded-2xl`، خلفية `surface-depth`، حدود ناعمة `border-border/40`، ضغطة `scale(0.96)` بربيع 120ms.
- كل بطاقة: أيقونة كبيرة (28px) بلون accent الخاص بالتطبيق (نفس ألوان `BottomNav` الحالية) + عنوان + وصف قصير سطر واحد.
- الأيقونة المركزية: شعار SmartHub أو رمز نقطة/شمعة/محراب — دائرة بحجم 72px مع توهج خفيف من `--live`.
- Motion: staggered fade-in للبطاقات عند فتح البوابة.
- Full RTL/LTR support، بدون كسور.

## ما لا يتغيّر

- الميزات نفسها، بياناتها، سلوكها الداخلي، RLS، Edge Functions.
- التصميم داخل كل ميزة.
- Auth flow.
- Living Ribbon (يبقى داخل Now).

## Deliverable

بعد هذه الخطة: `/` = بوابة مذهلة أنيقة تعرض 7 تطبيقات كأنها شاشة رئيسية لنظام تشغيل شخصي. أي ضغط على تطبيق يفتح تجربة كاملة الشاشة. زر عائم واحد يرجعك للبوابة. لا شريط سفلي مزدحم. الصفحة الرئيسية القديمة تصبح تطبيقاً منفصلاً باسم "الرئيسي" (`/now`).
