Generated by `scripts/capture-design.mjs` against the production build (and the Vite
dev server for the development-only gallery). The full matrices stay on disk under
`before/`, `after/`, `after-dashboards/`, `gallery*/`; this folder keeps a small,
reviewable subset.

Reproduce:

    bun run build && bunx vite preview --port 4173 --strictPort
    node scripts/capture-design.mjs --out verification/design/after

The gallery is a development route; capture it against `bun run dev` instead, and pass
`--base http://127.0.0.1:5199`.
